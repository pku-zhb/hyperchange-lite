# Focused material editor

The material editor uses the same single-renderer page as Notifications and Volume.
The pinned area contains only the sample; all controls scroll beneath it. A single
project selector chooses which controls to show, not a second preview scene.
Scrolling to or editing a setting automatically chooses the representative card.

Multiple material scopes use ordinary notifications as a core sample. Specific
Control Center radii show one matching tile/slider/card; volume-timer radius shows
the timer. Existing user-selected backgrounds remain loaded automatically, and
preview day/night follows the system. No background or replay toolbar occupies
space above the parameters.

Presets retain their exact values and material-only undo boundary, without recipe
paragraphs or compatibility essays. Titles, values, switches, sliders, +/- and
exact numeric entry are the visible adjustment UI. No stored parameter is silently
clamped when outside the common slider range.

The native normal-notification recipe is still an App sample; no pixel-identical
OEM scene or loaded-hook claim is made. The schematic/native status remains in
non-visible accessibility metadata rather than a caption.
